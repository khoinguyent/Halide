Upload in App Store Connect → each In-App Purchase → Image (Optional) / promotional image slot.

Files (RGB PNG, 1024×1024):
  halide_iap_promo_5gb_storage_1024.png   → product halide_storage_5gb_ext
  halide_iap_promo_10gb_storage_1024.png  → product halide_storage_10gb_ext
  halide_iap_promo_50gb_storage_1024.png  → product halide_storage_50gb_ext

If Apple’s upload UI shows different dimensions, re-export from Figma/Preview to match exactly.

Source renders (1536×1024 before square crop) may exist under the Cursor project assets folder; the *_1024.png files here are the ones to submit.
